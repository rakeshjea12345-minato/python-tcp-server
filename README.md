# Python TCP Server

A beginner-friendly TCP client-server application built using Python socket programming.

## Features
- TCP socket communication
- Client-server connection
- Sending and receiving messages
- IPv4 networking
- Port-based communication

## Technologies Used
- Python
- Socket Programming
- TCP/IP

## How to Run

1. Start the server:

   python server.py

2. Open another terminal and run:

   python client.py

## Server Configuration
- Host: 127.0.0.1
- Port: 5000

## Learning Objectives
Understanding TCP communication, sockets, IP addresses, and networking fundamentals.
